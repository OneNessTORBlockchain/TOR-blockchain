Generate or import

A generated wallet is a real Phantom-compatible Ed25519 key made by torchain wallet new. An import accepts a Phantom private key or a 12–24 word recovery phrase and derives the same address the chain uses. Both count toward the five-wallet limit.

SAFELY SAVE YOUR PRIVATE KEY

Pick a wallet, type the account password, and the node returns that wallet's private key (base58) plus its recovery words when the keystore has them. Nothing is logged, and the key is never returned without the password. Store it offline — anyone with the key controls the balance.

Tokens & prices

reading token logos…

Every row is the permanent public token record (GET /api/tokens/public, GET /api/public/tokens): symbol, name, mint address, supply, circulating supply, holders, owner, AMM price and market cap in TOR. Balances are public too — GET /api/public/balances lists every address, and GET /api/public/tokens/<SYMBOL>/holders lists every holder. Only sending needs a signature. Prices are quoted in TOR only — no fiat rate exists on this node. Each logo is the token's public metadata image (CoinGecko, DexScreener fallback, cached by this node), the launcher image, or a generated identicon when no source knows the ticker.
