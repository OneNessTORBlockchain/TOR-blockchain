per-transaction privacy · nothing expires

Privacy

read the rule
reading /api/privacy…

The 30-day window is gone: the ledger keeps every record forever and seals nothing. The sending wallet chooses public (its address is on chain) or anonymous (the record shows {{ privacy_label }}) before every send. Only the sender's own address is ever hidden — the receiver always stays on the record. The token table (GET /api/tokens/public) and the public balance sheet (/api/public/balances, /api/public/ledger, /api/public/totals) are public ledger data and stay readable forever. Reading is public; spending still needs the owner's signature (POST /api/wallets/<name>/challenge → /session).
