Developer API keys

The versioned developer API lives at /api/v1/<endpoint> and requires a key: curl -H "x-api-key: otd_…" /api/v1/chain.info. Keys are paid from your own wallet on-chain and expire; the key itself is shown once. The website you are reading uses your wallet session instead — no key needed there.

Metadata lives on IPFS: /api/ipfs/status · /api/ipfs/resolve · /api/ipfs/pin (admin + Pinata).
