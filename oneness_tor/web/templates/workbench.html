Deploy

Deploy a DarkWeb app to get a real .onion URL, or a Rust program to compile it and register an owner-only program on the chain.

DarkWeb: Tor's control port performs ADD_ONION and points /builds/<id>/ at this node — the answer is the onion URL, or the exact Tor error. Rust: cargo build --release runs for real; the binary is sha3-hashed and stored as a program owned by the deploying wallet (only that wallet sees its source, state and build, and only it can manage/run it). The chain charges no transaction fee; nodes and platforms add their own fees.
